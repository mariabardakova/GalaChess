Что реализовано:
- Доска 10×10 с разными зонами: углы, центр, середина
- Фигуры с логикой:
  - Король: ход на соседние клетки + прыжок из центра на изначально пустые
  - Пешка: в своём углу — только диагональ без взятия; вне угла — как король
  - Ладья / Слон: в углах — сложные ходы с ответвлениями; вне углов — меняются местами (ладья ходит как слон и наоборот)
- Режимы:
  - `Хочу играть! [белые|чёрные]` — человек vs бот
  - `Я наблюдатель` — бот vs бот (консольный вывод)
- Победа: два короля в центре ИЛИ уничтожение всех королей противника

Запуск
1. Скомпилировать проект
2. Запустить `com.example.demo.ui.HelloApplication`
3. В консоли выбрать режим:
   - Хочу играть! белые
   - Хочу играть! чёрные
   - Я наблюдатель

Управление
- Клик по своей фигуре — выбор
- Клик по допустимой клетке — ход
- Ход бота — автоматически через 1 сек
- Таймер — 5 минут на партию
